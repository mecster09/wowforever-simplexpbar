# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues. Use the `gh` CLI for issue operations; infer the repository from its Git remote.

- Create issues with `gh issue create`; use `--body-file` for multiline text.
- Read issues and comments with `gh issue view <number> --comments`.
- List issues with `gh issue list`, using appropriate state and label filters.
- Comment, label, and close issues with `gh issue comment`, `gh issue edit`, and `gh issue close`.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read the issue and its comments.

## Pull requests as a triage surface

PRs as a request surface: no.
